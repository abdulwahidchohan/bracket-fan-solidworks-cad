# SolidWorks Files Directory

This folder is intended for original SolidWorks project files associated with the Bracket Fan academic CAD project.

---

## File Availability & Usage

- **Available File:** `Fan.SLDPRT` (SolidWorks Part file).
- **Software Compatibility:** Users require SolidWorks 2020 or a newer compatible version to open native CAD files.
- **Sharing Protocol:** Native files should be uploaded and maintained here only when available and approved by all team members for public academic sharing.
- **CAD Representation:** Screenshots and rendered images are visual previews and are not substitutes for editable CAD files.
- **Verification Rule:** The availability of a rendered image or screenshot does not prove the availability of underlying source models. No source files are claimed as available unless physically present in this directory.
