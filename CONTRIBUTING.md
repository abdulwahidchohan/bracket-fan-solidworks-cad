# Contribution Guidelines

Thank you for your interest in contributing to the **Bracket Fan SolidWorks CAD** academic repository.

---

## Guidelines for Contributions

We welcome suggestions and contributions that maintain academic integrity and technical accuracy. Please follow these principles when submitting issues or pull requests:

### 1. Reporting Issues & Documentation Corrections
- **Broken Links:** Report any broken file links, image paths, or external URLs via GitHub Issues.
- **Documentation Errors:** Suggest corrections for typos, formatting errors, or unclear technical explanations.

### 2. Suggesting CAD Improvements
- Recommendations for refining component geometry, adding missing assembly mates, or organizing feature trees are welcome.
- Please detail any proposed SolidWorks feature updates clearly in your pull request description.

### 3. Respecting Authorship & Academic Integrity
- **Authorship:** Respect the original student team's academic authorship.
- **No Fabricated Data:** Do not add unverified or fabricated performance results, stress numbers, or CFD simulation claims.
- **Visual Material Integrity:** Do not replace original project visuals with unrelated third-party images.
- **Reference Photo Labeling:** Never present reference photographs of existing real fans as student-fabricated CAD outputs or manufactured prototypes.
